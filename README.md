### 01. Multi-Camera Person Tracking & Re-ID CCTV

- **Type:** Team Project
- **Platform:** NVIDIA Jetson Orin Nano
- **Core Technologies:** YOLO, ByteTrack, OSNet Re-ID, OpenCV, MQTT
- **Goal:** 여러 카메라 구간을 이동하는 사람을 탐지·추적하고 동일인 여부와 이동 경로를 판단하는 시스템
