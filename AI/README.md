# AI Projects

온디바이스 환경에서 직접 구현한 Computer Vision 및 실시간 AI 프로젝트입니다.

| 프로젝트 | 핵심 내용 | 주요 기술 |
|---|---|---|
| [Jetson AI Rock–Paper–Scissors](./jetson-rps-game) | 손을 실시간으로 분류해 1인전·2인전·하나 빼기·묵찌빠를 제공하는 4모드 웹 게임 | Jetson Orin Nano, MobileNetV2, TensorRT, OpenCV, Flask |
| [Multi-Camera CCTV Re-ID](./multicam-cctv-reid) | 여러 카메라 사이에서 동일 인물을 연결하고 경로 및 이동 상태를 판단하는 팀 프로젝트 | YOLO, ByteTrack, OSNet, MQTT, Jetson Orin Nano |

각 프로젝트 폴더에는 구현 내용, 실행 환경, 핵심 기술과 원본 코드를 정리했습니다.
