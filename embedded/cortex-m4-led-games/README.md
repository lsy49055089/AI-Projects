# STM32 LED 미니게임 프로젝트 사용설명서

## 시연 영상

- [STM32 LED 미니게임 시연 영상](./demo.mp4)

## 1. 프로젝트 개요

본 프로젝트는 **STM32 NUCLEO-F411RE 보드**를 이용하여 제작한 LED 기반 미니게임입니다.

사용자는 시작 화면에서 원하는 게임을 선택할 수 있으며, 선택 가능한 게임은 다음과 같습니다.

1. **반응속도 게임**
2. **LED 기억력 게임**

LED, 버튼, LCD, 부저를 이용하여 게임 상태를 표시하고 사용자 입력을 처리합니다.

## 3. 프로젝트 주요 기능

### 3.1 게임 선택 메뉴

프로그램이 시작되면 LCD와 UART 터미널에 게임 선택 메뉴가 표시됩니다.

```text
SELECT GAME
<REACT  MEMORY>
```

버튼 기능은 다음과 같습니다.

| 버튼   | 메뉴 기능      |
| ---- | ---------- |
| BTN3 | 반응속도 게임 선택 |
| BTN1 | 기억력 게임 선택  |

게임을 선택하면 선택 효과음이 출력되고 해당 게임이 시작됩니다.

---

## 4. 반응속도 게임

### 4.1 게임 설명

반응속도 게임은 무작위로 켜지는 LED를 확인한 후, 해당 LED에 대응하는 버튼을 제한시간 안에 누르는 게임입니다.

총 10라운드로 구성되며 라운드가 진행될수록 제한시간이 짧아집니다.

### 4.2 LED와 버튼 대응 관계

| 켜진 LED | 눌러야 하는 버튼 |
| ------ | --------- |
| LED1   | BTN3      |
| LED2   | BTN2      |
| LED3   | BTN1      |

UART 터미널에는 다음과 같이 표시됩니다.

```text
LED REACTION GAME - 10 ROUND
BTN1 -> LED3
BTN2 -> LED2
BTN3 -> LED1
```

### 4.3 게임 진행 순서

1. 게임 시작 음악이 재생됩니다.
2. LCD와 UART에 현재 라운드가 표시됩니다.
3. 무작위 대기시간 동안 버튼을 누르지 않고 기다립니다.
4. LED 1개가 무작위로 켜집니다.
5. 켜진 LED에 대응하는 버튼을 누릅니다.
6. 제한시간 안에 올바른 버튼을 누르면 다음 라운드로 진행합니다.
7. 잘못된 버튼을 누르거나 제한시간을 초과하면 게임이 종료됩니다.
8. 10라운드를 모두 성공하면 게임 클리어 화면이 표시됩니다.

### 4.4 제한시간

반응속도 게임은 다음과 같이 진행될수록 제한시간이 감소합니다.

```text
1라운드 제한시간 : 약 1000ms
마지막 라운드 제한시간 : 약 550ms
```

따라서 뒤쪽 라운드로 갈수록 빠른 반응이 필요합니다.

### 4.5 실패 조건

다음 조건 중 하나가 발생하면 게임 오버가 됩니다.

* LED가 켜지기 전에 버튼을 누른 경우
* 켜진 LED와 다른 버튼을 누른 경우
* 여러 버튼을 동시에 누른 경우
* 제한시간 안에 버튼을 누르지 못한 경우

게임 오버 시 LCD와 UART에 실패 원인이 표시되고 게임 종료 음악이 재생됩니다.

## 5. LED 기억력 게임

### 5.1 게임 설명

LED 기억력 게임은 일정한 순서로 켜지는 LED 패턴을 기억한 후, 동일한 순서대로 버튼을 입력하는 게임입니다.

라운드가 진행될수록 기억해야 하는 LED의 개수가 증가합니다.

### 5.2 게임 진행 순서

1. 기억력 게임 시작 음악이 재생됩니다.
2. LED가 일정한 순서대로 점등됩니다.
3. 사용자는 LED가 켜진 순서를 기억합니다.
4. LED 출력이 끝나면 버튼으로 동일한 순서를 입력합니다.
5. 입력 순서가 모두 맞으면 다음 라운드로 진행합니다.
6. 입력 순서가 틀리면 게임이 종료됩니다.
7. 마지막 라운드까지 성공하면 게임 클리어 화면이 표시됩니다.

### 5.3 입력 방법

LED와 버튼의 대응 관계는 반응속도 게임과 동일합니다.

| LED  | 대응 버튼 |
| ---- | ----- |
| LED1 | BTN3  |
| LED2 | BTN2  |
| LED3 | BTN1  |

### 5.4 실패 조건

다음과 같은 경우 게임 오버가 됩니다.

* LED 패턴과 다른 버튼을 누른 경우
* 버튼 입력 순서가 틀린 경우
* 여러 버튼을 동시에 누른 경우
* 정해진 시간 안에 입력하지 못한 경우

## 6. LCD 표시 내용

LCD는 현재 게임 상태를 사용자에게 알려주는 역할을 합니다.

표시되는 주요 내용은 다음과 같습니다.

* 게임 선택 메뉴
* 선택된 게임 이름
* 게임 시작 안내
* 현재 라운드
* 버튼 입력 대기
* 성공 또는 실패 여부
* 게임 클리어
* 게임 오버

예시:

```text
SELECT GAME
<REACT  MEMORY>
```

```text
REACTION GAME
ROUND 01 / 10
```

```text
MEMORY GAME
WATCH LED
```

```text
GAME OVER
TRY AGAIN
```

## 8. UART 터미널 출력

UART 터미널에서는 게임 진행 상황과 디버깅 정보를 확인할 수 있습니다.

통신 설정은 다음과 같습니다.

| 설정           | 값      |
| ------------ | ------ |
| Baud Rate    | 115200 |
| Data Bit     | 8 bit  |
| Parity       | None   |
| Stop Bit     | 1 bit  |
| Flow Control | None   |

반응속도 게임 출력 예시는 다음과 같습니다.

```text
==============================
 LED REACTION GAME - 10 ROUND
 BTN1->LED3, BTN2->LED2, BTN3->LED1
 Limit: 1000ms -> 550ms
==============================

[ROUND 1/10] LIMIT = 1000 ms
WAIT... do not press early
GO! LED3 ON
```

정상 입력 시:

```text
CORRECT!
REACTION TIME = 425 ms
```

시간이 초과된 경우:

```text
TIME OUT! LIMIT = 1000 ms
GAME OVER at round 1
```

## 9. 프로젝트 실행 방법

### 9.1 하드웨어 연결

1. NUCLEO-F411RE 보드를 USB 케이블로 PC에 연결합니다.
2. LED, 버튼, LCD, 부저가 확장보드와 정상적으로 연결되어 있는지 확인합니다.
3. 보드에 전원이 정상적으로 공급되는지 확인합니다.

### 9.2 터미널 설정

1. Tera Term을 실행합니다.
2. NUCLEO 보드의 ST-LINK Virtual COM Port를 선택합니다.
3. Baud Rate를 `115200`으로 설정합니다.
4. Data Bit는 `8`, Parity는 `None`, Stop Bit는 `1`로 설정합니다.

### 9.3 컴파일

프로젝트 폴더에서 터미널을 실행한 후 다음 명령어를 입력합니다.

```bash
make clean
make all
```

### 9.4 보드 다운로드 및 실행

컴파일이 완료되면 다음 명령어를 입력합니다.

```bash
make run
```

컴파일과 다운로드를 한 번에 실행하려면 다음 명령어를 사용할 수 있습니다.

```bash
make all run
```

다운로드가 완료되면 보드가 리셋되고 프로그램이 시작됩니다.

## 12. 주요 소프트웨어 기능

### 12.1 버튼 입력 처리

버튼 입력은 다음 상태를 구분하여 처리합니다.

* 아무 버튼도 누르지 않은 상태
* 버튼 1개가 눌린 상태
* 여러 버튼이 동시에 눌린 상태
* 버튼이 눌렸다가 해제된 상태

버튼을 계속 누르고 있을 때 하나의 입력이 여러 번 처리되지 않도록 버튼이 모두 해제될 때까지 기다리는 기능을 사용합니다.

### 12.2 LED 제어

LED 제어 기능은 다음과 같습니다.

* LED 전체 끄기
* 특정 LED 켜기
* LED 패턴 출력
* 게임 종료 시 LED 초기화

### 12.3 타이머 사용

타이머는 다음 기능에 사용됩니다.

* 반응속도 제한시간 측정
* 무작위 대기시간 처리
* LED 점등시간 제어
* 버튼 입력 제한시간 처리
* 부저 음 길이 조절

### 12.4 난수 사용

반응속도 게임에서는 켜질 LED와 대기시간을 예측하기 어렵게 하기 위해 난수를 사용합니다.

기억력 게임에서는 매 라운드마다 LED 패턴을 생성하는 데 난수를 사용합니다.

## 13. 주의사항

* 여러 버튼을 동시에 누르면 정상 입력으로 처리되지 않을 수 있습니다.
* 반응속도 게임에서 LED가 켜지기 전에 버튼을 누르면 실패 처리됩니다.
* 게임 시작 전에 이전에 눌려 있던 버튼을 모두 놓아야 합니다.
* LCD나 UART 출력이 보이지 않으면 보드의 RESET 버튼을 누릅니다.
* Tera Term의 Baud Rate가 `115200`인지 확인합니다.
* 다운로드가 되지 않으면 USB 연결과 ST-LINK 인식 상태를 확인합니다.
* 프로그램 실행 중 하드웨어 배선을 변경하지 않습니다.

## 14. 문제 해결

### 14.1 UART 터미널에 문자가 출력되지 않는 경우

* Tera Term의 COM Port가 올바른지 확인합니다.
* Baud Rate가 `115200`인지 확인합니다.
* 보드의 RESET 버튼을 누릅니다.
* USB 케이블을 다시 연결합니다.

### 14.2 버튼이 계속 입력되는 경우

버튼을 계속 누르고 있으면 반복 입력이 발생할 수 있습니다.

프로그램에서 버튼이 해제될 때까지 기다리는 기능이 정상적으로 호출되는지 확인합니다.

```c
Button_Wait_All_Released();
```

### 14.3 LED와 버튼 대응이 다른 경우

반응속도 게임의 대응 관계는 다음과 같습니다.

```text
BTN1 -> LED3
BTN2 -> LED2
BTN3 -> LED1
```

배선과 프로그램의 핀 설정이 동일한지 확인합니다.

### 14.4 첫 라운드부터 시간 초과가 발생하는 경우

* 버튼 입력 함수가 실제 버튼 핀을 올바르게 읽는지 확인합니다.
* 버튼이 Active Low인지 확인합니다.
* 타이머가 정상적으로 시작되었는지 확인합니다.
* LED가 켜진 후 타이머 측정이 시작되는지 확인합니다.
* 버튼이 눌리기 전에 타이머가 종료되지 않는지 확인합니다.

* 하나의 시스템에서 두 가지 게임 제공
* LCD를 이용한 게임 상태 표시
* UART를 이용한 실시간 진행 상황 출력
* 버튼 동시 입력 및 선입력 예외 처리
* 타이머를 이용한 반응시간 측정
* 난수를 이용한 게임 패턴 생성

* 라운드 진행에 따른 난이도 증가

## 16. 프로젝트 실행 요약

```text
1. NUCLEO 보드를 PC에 연결한다.
2. Tera Term을 115200 Baud Rate로 실행한다.
3. 프로젝트 폴더에서 make all run을 입력한다.
4. BTN3 또는 BTN1을 눌러 게임을 선택한다.
5. LCD와 LED의 안내에 따라 게임을 진행한다.
6. 게임 종료 후 보드를 리셋하여 다시 시작한다.
```

## 17. 프로젝트 결과

본 프로젝트를 통해 STM32의 GPIO, 버튼 입력, LED 출력, UART 통신, 타이머, LCD, 부저 및 난수 처리 기능을 하나의 프로그램에 통합하였습니다.

단순한 LED 제어를 넘어 버튼 입력 시점과 입력 순서를 판정하고, 게임 상태에 따라 LCD와 부저를 제어하는 미니게임 시스템을 구현하였습니다.
